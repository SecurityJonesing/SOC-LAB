SOC Lab — Diagrams

Eight reference diagrams: network topology, the full kill chain, the AD attack-surface map, hybrid identity architecture, agent governance, the bridge/socket lesson, the recovery ladder, and the phase map. Scroll down for all eight.

1. Lab network topology

Every packet crosses pfSense on the way between VLANs. Two deliberate exceptions exist in an otherwise default-deny Range fence: the green line (Wazuh log ingest, existing since Phase A.5) and the amber line (Entra Connect sync, the one INFRA20→RANGE30 exception, narrow and reviewed). The dashed boxes are phantom AD computer objects — directory entries, not live VMs.

2. The full kill chain — one story, confirmed at every stage

Every stage runs manually — no orchestration tool executes this chain autonomously. A Wazuh or Suricata detection is confirmed before moving to the next stage. Scope stops after win11-ws02 is compromised; DCSync provides domain-wide credential material without needing a shell on dc01 itself.

3. AD attack surface — everything converges on one point

Six deliberately planted misconfigurations, each a distinct, real-world attack primitive, all leading to the same place: Domain Admin–equivalent access without ever touching the Domain Admins group directly. This is what BloodHound's shortest-path analysis is built to surface.

4. Hybrid identity — one continuous story, on-prem to cloud

Entra Connect syncs one direction, on-prem to cloud — not the two-way sync it's sometimes assumed to be. AADInternals/ROADtools extend the on-prem kill chain into the tenant, the deliberate connective piece between the AD environment and the IAM/Entra track.

5. Agent governance — four identities, none of them mine

Every non-human actor in this lab gets its own credential, least-privilege scope, and a separate audit trail. wazuh-triage-01 is the specialist; triage-router-01 is the plumbing underneath it. Shuffle and the Entra Connect sync account are registered the same way, even before they're built.

6. Why the attack VM went dark — the bridge is a wall socket

A VM plugs into a bridge, not a NIC. Move the bridge's uplink cable to a different NIC, and every VM still pointed at the old bridge goes dark — silently, with no error anywhere. Kept from the original diagram set — the lesson is foundational and still applies to every VM in this lab.

7. The recovery ladder — climb down until something works

Never make a change that could cut off the only access path. Confirm the next rung down works before it's needed — the green rungs are physical and need no network, no config, no Java. That's why they're always the true fallback.

8. Phase map — what unlocks what

A.5 must pass before C — no attack code on an unfenced network. B must pass before C — no SIEM, nothing to detect with. C.6/C.7 are locked, deliberately-reduced scope. G is deferred, attempted only once F and E are stable.
